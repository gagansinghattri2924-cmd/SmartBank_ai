# SmartBank AI – Intelligent RBI-Powered Digital Banking Platform

**SmartBank AI** is a modern, interactive digital banking simulation and financial literacy platform built with React, Vite, Tailwind CSS, and Recharts. Designed with a Midnight Obsidian and Champagne Gold interface and smooth UI transitions, it combines everyday digital banking workflows with an intelligent, regulation-grounded AI assistant.

## Key Features

- **Simulated Digital Banking:** Includes one-click demo authentication, Savings and Current accounts, simulated deposits/withdrawals, beneficiary management, virtual debit/credit cards, UPI payments with mock QR previews, and NEFT/IMPS/RTGS transfers that enforce real-world RBI transaction limits.
- **Unified Dashboard & Ledger:** Displays real-time KPI analytics alongside an integrated **Transactions & Statements** subpart featuring clickable receipts, multi-filter search, CSV export, and printable account statements.
- **RBI-Powered RAG AI Assistant & Expense Analyzer:** Powered by a client-side Retrieval-Augmented Generation (RAG) pipeline over an RBI knowledge base (covering Zero Liability, RB-IOS 2021, failed transaction TAT, KYC/V-CIP, and DICGC insurance). It supports English and Hindi, displays clickable official citations and a live RAG Pipeline Inspector, and handles natural-language expense tracking, budget updates, and spending analysis directly in chat.
- **Fraud Awareness & Knowledge Center:** Features a searchable banking library, live RBI document ingestion, Helpline 1930 guidance, and an interactive "Spot the Scam" quiz.
